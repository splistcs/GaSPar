## 1.	Resumo do Negócio
O sistema GaSPar é uma maneira de controlar de forma inteligente o acesso ao estacionamento do IFSP campus salto, utilizando um app android.

## 2.	Objetivo do Sistema
O objetivo do projeto é solucionar as dores registradas no IFSP Salto em relação ao sistema atual de
estacionamento, modernizando a entrada e facilitando o cadastro e o contorno de situações possivelmente
falhas no modelo atual.
